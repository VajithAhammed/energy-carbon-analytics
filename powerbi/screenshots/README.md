# Screenshots

Empty on purpose — this sandbox has no Power BI Desktop (a Windows GUI
application) to actually render the dashboard and capture screenshots
from. See `powerbi/README.md` for why, and `powerbi/dashboard_pages.md`
for the full page-by-page design to build from.

Once you've built the report in Power BI Desktop following that design,
drop your screenshots here — one per page is the standard for a GitHub
README (`executive_summary.png`, `energy_performance.png`,
`carbon_sustainability.png`, `anomaly_monitoring.png`, `forecasting.png`,
`management_scenario.png`) — and the root README can reference them
directly.
