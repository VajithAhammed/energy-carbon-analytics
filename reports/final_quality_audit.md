## Findings from this audit that weren't previously flagged

1. **Repo size, precisely measured (not estimated):** the actual
   git-trackable size (respecting `.gitignore`) is **67MB** — confirmed
   with `git ls-files | xargs du -ch`, not guessed. Comfortably clear of
   any GitHub concern.
2. **Data duplication, found and evaluated, not silently left in:**
   8 files are duplicated between `data/processed/` and
   `powerbi/dashboard/` (~13-14MB of redundancy). Considered removing
   it, decided to keep it: `powerbi/dashboard/` is meant to be the one
   self-contained folder someone points Power BI Desktop at (per
   `powerbi/README.md`'s setup instructions) — splitting that import
   across two different folders would be worse for that specific
   purpose. A deliberate tradeoff, documented here rather than left
   unexplained.
3. **Stray `__pycache__` directory** — found and removed (see table
   above).

## What this audit does NOT claim

- That the SQL and Power BI artifacts work correctly when actually run
  against live PostgreSQL / Power BI Desktop — that's genuinely
  untested here, and both `reports/postgres_setup.md` and
  `powerbi/README.md` say so directly rather than implying otherwise.
- That any business finding generalizes beyond this synthetic dataset.
- That every possible bug has been found — only that the specific
  checks in the brief's own audit list were actually performed, with
  evidence, in this session.
